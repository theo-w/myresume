01
数字分身与数字员工执行底座 MVP 迭代中

个人项目 · 通用 AI 执行底座，探索分身管理任务、员工执行反馈与结果核验的闭环。

  • 围绕目标拆解、动态任务编排、员工反馈、证据核验与验收设计工作流；坚持单 Agent 优先，仅在任务复杂度、质量或风险需要时再拆分协作。
  • 持续完善来源角色与证据用途区分，避免将检索结果或文章直接当作已核实事实；状态接口有响应记录，但启动链路、实时调研、失败后重试和最终验收仍需端到端复测。
个人贡献与关键决策

持续梳理分身与员工之间的任务分配、状态反馈、证据分类与独立验收机制；目标是让系统围绕目标持续推进，而不是模拟固定岗位。线上 MVP 已持续迭代，最近版本补充来源角色与证据用途标记；完整启动、真实调研、失败恢复及端到端验收仍待复测，不将部署成功等同于任务已跑通。

04
Mini Agent Harness · Agent 工程学习实验室 公开教学 Demo

个人学习项目 · 从最小 ReAct 循环出发，用失败驱动的方式理解每个 Agent 组件为什么出现。

  • 按“模型 → Tool → Loop → 上下文 → 护栏 → Trace / Eval → Skill”逐层迭代，并用 SDD 记录 M1.2–M1.10 的规格、计划、任务、实现与验证证据。
  • 公开版提供 7 章从零建造课程与 8 零件、256 种组合的乐高实验，用任务完成、安全、证据三张结论卡对比“有 / 无组件”的差异。
  • 95 项确定性测试覆盖 256 组合、A/B 归因与无执行通道；当前是教学模拟，不调用模型 API、不执行真实工具。
能力边界与验证说明

这个项目用于学习 Agent 工程和做产品机制验证，不定位为生产级 Agent 平台。公开 Demo 的耗时、Token 与结论只解释确定性模拟中的机制关系，不代表真实模型或工具性能；真实 Trace 深挖视图只在本地数据就绪时开放。
